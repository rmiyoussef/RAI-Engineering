# Stack

> Technologies this project uses. ARCHITECT updates when stack changes.

- **OS:** Linux (zsh), git, GitHub (`gh` CLI for PRs/issues)
- **Distribution:** Bash installers (`setup.sh`, `update.sh`); no build step, no package manager
- **Automation:** Python 3 (`.ai/memory-timeline.py` generates `TIMELINE.md`)
- **Target-project stacks (knowledge, not this repo):** Laravel/PHP (service-layer guidelines in `knowledge/patterns/backend-service-layer-guidelines.md`), React/Mantine (`reference/mantine.md`, `knowledge/patterns/frontend-best-practices.md`), Docker/K8s/Terraform (`knowledge/infrastructure/devops-practices.md`)
